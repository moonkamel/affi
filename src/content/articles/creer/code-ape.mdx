Le code APE intrigue beaucoup de créateurs : on le découvre sur son avis de situation, on se demande s’il est « bon », et s’il a des conséquences. Rassure-toi : il sert surtout à l’INSEE pour ses statistiques. Voici où le trouver, à quoi il sert vraiment et comment le corriger.

## Où trouver ton code APE

- **L’avis de situation au répertoire Sirene**, téléchargeable gratuitement sur [avis-situation-sirene.insee.fr](https://avis-situation-sirene.insee.fr/) avec ton numéro SIREN ou SIRET.
- **L’extrait Kbis**, si ton entreprise est immatriculée au registre du commerce et des sociétés.
- **L’[annuaire des entreprises](https://annuaire-entreprises.data.gouv.fr/)** de l’État, qui reprend les données publiques du répertoire Sirene.

Il se présente sous la forme de **4 chiffres et 1 lettre**, par exemple **62.01Z** (programmation informatique) ou **74.10Z** (activités spécialisées de design).

## À quoi sert (et ne sert pas) le code APE

| Il sert à… | Il ne détermine pas… |
|---|---|
| Classer ton entreprise dans les statistiques de l’INSEE | Ton régime fiscal ou social |
| Donner un premier indice de ton secteur à tes interlocuteurs (banque, assureur) | Ta convention collective, qui dépend de ton activité réelle |
| Remplir certains formulaires administratifs | Tes droits à exercer une activité réglementée |

Les informations de l’avis de situation, en dehors de l’identification de l’entreprise, n’ont de valeur que statistique, rappelle l’INSEE. Un code « imparfait » n’a donc en général aucune conséquence.

## Changer ton code APE

**Si ton activité a changé** : déclare d’abord la modification sur le guichet unique, [formalites.entreprises.gouv.fr](https://formalites.entreprises.gouv.fr/). L’INSEE mettra ensuite ton code à jour.

**Si le code attribué ne correspond pas à ton activité réelle** :

1. Remplis le **formulaire de demande de modification** sur le site de l’INSEE.
2. Joins le **descriptif de ton activité** (répartition de ton chiffre d’affaires par activité).
3. Compte environ **20 jours ouvrés** de délai d’instruction.

Une entreprise immatriculée depuis moins d’un mois peut contester son code en joignant son Kbis. Évite les demandes à répétition sans justification : elles sont refusées.

<Callout title="NAF 2025 : un nouveau code au 1er janvier 2027">
  La nomenclature des activités change. À partir du 1er janvier 2027, toutes les entreprises actives, micro-entrepreneurs compris, reçoivent un nouveau code APE issu de la NAF 2025. Le format reste le même (4 chiffres et 1 lettre), mais les codes changent. Tu peux déjà consulter ton futur code sur le site Sirene de l’INSEE, avec ton numéro SIREN, et demander une correction si besoin. Aucune démarche n’est obligatoire, et le nouveau code ne crée ni droit ni obligation.
</Callout>

## Le code APE sur tes factures ?

Le code APE ne fait pas partie des mentions obligatoires d’une facture. Ce qui est obligatoire, ce sont notamment ton numéro **SIREN ou SIRET**, ton nom ou ta dénomination, ton adresse et, selon ta situation, ton numéro de TVA. Retrouve la liste complète dans notre guide des [mentions obligatoires d’une facture](/facturation/mentions-obligatoires-facture/).

Avec la facture électronique, chaque facture à un client professionnel doit porter **son numéro SIREN**. Dans la plupart des TPE, le fichier clients a été rempli au fil des années : SIREN manquants, numéros mal recopiés, entreprises fermées depuis longtemps. Cet outil fait le ménage pour toi, ligne par ligne, dans la base officielle de l’État.

<SirenChecker />

## Comment utiliser l’outil

1. **Exporte ton fichier clients** depuis ton logiciel de facturation ou Excel, au format CSV (« Enregistrer sous », puis « CSV séparateur point-virgule »). Tu peux aussi copier les colonnes dans Excel et les coller dans le cadre.
2. **Vérifie les colonnes** détectées : le nom, le SIREN ou SIRET, et le code postal si tu l’as.
3. **Lance la vérification**, puis télécharge le fichier complété. Il reprend tes colonnes d’origine et ajoute le résultat, le SIREN vérifié, le SIRET du siège, le nom officiel, l’adresse, le code NAF et le numéro de TVA calculé.
4. **Corrige les lignes signalées** et réimporte le fichier dans ton logiciel.

## Comment lire les résultats

| Résultat | Ce que ça veut dire | Que faire |
|---|---|---|
| ✅ Active | Entreprise trouvée et en activité | Rien, reporte le SIREN dans ton logiciel |
| ⛔ Fermée | Entreprise radiée ou cessée | Archive le client, vérifie s’il reste des impayés |
| ⚠️ À vérifier | Plusieurs entreprises portent un nom proche, ou le nom ne correspond pas au numéro | Confirme le SIREN avec ton client ou sur une de ses factures |
| ❓ Introuvable | Aucun résultat | Ajoute le code postal, corrige le nom, ou demande le SIREN au client |
| ❌ Erreur | Numéro mal formé (clé de contrôle fausse) | Erreur de saisie : reprends le numéro sur un document du client |

<Callout title="Les particuliers n’ont pas de SIREN">
  La réforme concerne les factures entre professionnels. Tes clients particuliers n’ont pas de SIREN : pour eux, la facture électronique n’est pas obligatoire, mais tu devras transmettre certaines données à l’administration (e-reporting). Garde-les dans ton fichier, sans SIREN.
</Callout>

## Pourquoi c’est le bon moment

- **Depuis le 1er septembre 2026**, toutes les entreprises doivent pouvoir recevoir des factures électroniques.
- **Au 1er septembre 2027**, les PME, TPE et micro-entreprises devront aussi les émettre, avec les [nouvelles mentions obligatoires](/facturation/mentions-obligatoires-facture/), dont le SIREN du client.
- Le SIREN sert aussi à retrouver ton client dans l’[annuaire de la facturation électronique](/facturation/annuaire-facturation-electronique/), qui indique où il reçoit ses factures.

Un fichier propre maintenant, c’est un passage sans accroc à ton futur [logiciel de facturation](/facturation/logiciel-de-facturation/) ou à ta [plateforme agréée](/facturation/plateforme-agreee-facture-electronique/).

## Et au-delà de 50 lignes ?

La version gratuite vérifie les 50 premières lignes. Une version complète est en préparation : fichiers de plusieurs milliers de lignes et **surveillance de tes clients**, avec une alerte si l’un d’eux ferme ou fait l’objet d’une procédure collective (redressement, liquidation).

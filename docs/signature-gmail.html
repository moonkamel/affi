Comment l’installer dans Gmail
  1. Sélectionne la signature ci-dessous, du logo à la dernière ligne, puis copie-la (Ctrl+C ou Cmd+C).
  2. Dans Gmail sur ordinateur : roue dentée → Voir tous les paramètres → onglet Général → Signature → Créer.
  3. Colle la signature dans le cadre, puis choisis-la pour les nouveaux e-mails et les réponses.
  4. En bas de la page : Enregistrer les modifications.
